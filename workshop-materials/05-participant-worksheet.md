## 2. Scan the interface

Use the S.C.A.N. E.R. lenses:

- **State:** current status, progress, data freshness, result of actions
- **Clarity:** labels, units, hierarchy, relationships, user language
- **Action:** next step, risky actions, consequences, user control
- **Navigation:** location, workflow progress, preserved context
- **Error handling:** prevention, validation, explanation, recovery
- **Reach and robustness:** color, contrast, keyboard, target size, interruptions, expertise

For scientific tools, also inspect measured versus commanded values, units, uncertainty, calibration, provenance, alarms, timestamps, and handover.
